# Shindo CLI

Herramienta de línea de comandos para buscar contenido de anime y manga.

## Requisitos
- Python 3
- fzf (sudo apt install fzf)

## Instalación
1. Clonar el repositorio.
2. Instalar dependencias: `pip install -r requirements.txt`
3. Dar permisos: `chmod +x main.sh`

## Uso
`./main.sh`
